# pc-store

A minimal demo "PC Store" static project.

Files:
- `index.html` — main page
- `style.css` — basic styles
- `script.js` — product rendering + simple cart stored in localStorage

Usage:
1. Open `index.html` in your browser.
2. Click "Add to cart" to add demo items (cart stored in `localStorage`).
